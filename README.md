# Boot VR Game Prototype (Kitchen Time Management)

A 3D simulation and game prototype built using **Unity** and **Blender** as part of the *Immersive Media* course at **Humboldt University of Berlin**.

![VR Kitchen Management Gameplay](boot_gif.gif)
 

---

## 📌 Project Overview

This project was developed during an exchange term at Humboldt University of Berlin for a 4th-year elective course focused on **Immersive Media and Game Development**. 

The main objective of the course was to gain hands-on experience in 3D modeling and game engine mechanics using **Unity** or Godot. The central concept of this project is a **Kitchen Time Management** simulation where players prepare recipes interactively. In this prototype, players can assemble a modular burger by combining individual ingredients step-by-step.

Designed with future **Virtual Reality (VR)** scaling in mind, the mechanics focus on object interaction, spatial organization, and modular component assembly.

---

## 🕹️ Key Features

* **Modular Recipe Assembly:** Mechanically stack ingredients (bun, patty, lettuce, tomato, cheese, etc.) to complete burger orders.
* **Custom 3D Ship Model:** Created from scratch in Blender to serve as the unique setting/environment anchor.
* **Time Management Gameplay Loop:** Interactive stations designed to simulate kitchen pressure and task management.
* **VR-Ready Architecture:** Designed with physics-based interaction principles intended for easy porting to VR headsets (e.g., Meta Quest / SteamVR).
